# Virtual Classroom Platform

A web application that allows students and teachers to participate in virtual classes.

## Features

- Student Registration and Login
- Teacher Login
- Virtual Class Creation
- Live Class Joining
- Notes and Material Sharing
- Discussion Forum
- Class Announcements

## Agile Development

This project is developed using 3 Sprints:

1. Sprint 1 - User Management
2. Sprint 2 - Live Classroom
3. Sprint 3 - Notes and Discussion
